# 密鑰生命週期

## Node 啟動密鑰

Node 密鑰是根啟動秘密。第一方客戶端只透過管理員流程使用它建立短效註冊權杖。註冊成功後必須刪除 Node 密鑰，日常 HTTP、WebSocket 或傳輸要求不得傳送它。

密鑰外洩、被複製到不受控系統或管理員交接時必須輪替。輪替會阻止新的舊密鑰啟動要求，但不會撤銷既有裝置憑證。

## 註冊權杖

權杖具完整性保護，綁定 Node 身分，限制時間與使用次數，並可限制裝置類型、名稱、擁有者及權限。資料庫只保存權杖雜湊。過期、撤銷或耗盡後回傳穩定錯誤碼，且不得重放。

## 裝置憑證

每個裝置取得獨立隨機憑證與 X25519 身分。憑證可個別撤銷。撤銷會終止 session、停止提供新的包裝內容密鑰、拒絕後續 Relay grant，並通知其他可信裝置。

## Relay grant

Relay grant 為短效，綁定 Relay、transfer、file、操作、位元組上限、到期與 nonce。Relay 身分金鑰由主要 Node 釘選。進入 drain 或移除後停止新工作，但不得過早刪除有效進行中分段。

## 緊急復原

- Node 密鑰遺失：替換密鑰並重新簽發註冊權杖
- 管理員 TOTP 遺失：使用離線管理復原流程並輪替 Node 憑證
- 裝置失竊：撤銷裝置、終止 session、檢查近期 grant，必要時輪替使用者秘密
- Relay 遭入侵：drain 並移除、撤銷未到期 grant、重新分配加密分段
