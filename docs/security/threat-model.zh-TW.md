# 威脅模型

## 保護資產

- Node 啟動密鑰與管理員 TOTP
- 裝置私鑰與裝置憑證
- 註冊與 Relay grant
- 包裝內容密鑰及加密分段
- 傳輸中繼資料、送達狀態與稽核歷史

## 信任邊界

主要 Node 負責使用者、裝置、傳輸與包裝密鑰授權。次要 Relay 只是不受信任的儲存與傳輸端點：可保存密文，但不得取得管理員憑證、資料庫密碼、Node 密鑰、裝置私鑰或明文內容。

探索、QR code、深層連結與網路可達性都不會授予信任。每個路由與 Relay 要求都必須使用已驗證裝置身分及有限範圍 grant。

## 主要威脅與控制

- Node 密鑰外洩：只用於簽發短效註冊 grant；輪替時不替換裝置憑證
- 權杖重放：綁定 Node、操作、物件、到期、nonce 與使用次數
- 裝置失竊：撤銷個別憑證並停止提供新的包裝密鑰
- 惡意 Relay：端對端加密、有限 grant、大小限制、身分釘選與雜湊驗證
- 路徑穿越：相對路徑正規化、平台衝突檢查與原子寫入
- 日誌洩漏：不得記錄秘密、明文訊息、推播檔名或包裝密鑰
- 偽造刪除：使用具授權與保留期限的簽章版本化 tombstone

## 復原假設

Node 密鑰遺失時可更換，既有裝置憑證保持有效。可信裝置失竊時須撤銷憑證，並檢查該裝置已下載內容。刪除無法回收接收端已匯出或複製的明文。
