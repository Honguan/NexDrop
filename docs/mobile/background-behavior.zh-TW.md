# 平台背景行為

## Android

可延後同步與續傳下載使用 WorkManager；只有使用者可見的持續傳輸才使用前景服務。排程前先持久化佇列，避免程序被終止或重建時遺失進度。必須遵守 Doze、省電、計量網路、充電、低儲存與過熱限制。

## Windows

桌面客戶端可隨使用者登入啟動並常駐系統匣。重啟、睡眠、切換網路或應用程式更新後，從已驗證分段邊界恢復。通知以 transfer 與狀態版本去重。

## Web

Web Push 只是可選喚醒提示，不代表已送達。頁面開啟後同步中繼資料，收到確認前不得宣稱送達。瀏覽器儲存配額與背景暫停可能延後檔案本體。

## 瀏覽器擴充套件

Manifest V3 service worker 生命週期短暫。事件返回前先保存工作，只用 alarm 執行有限重試，不在記憶體維持長時間傳輸狀態。

## 使用者控制

提供自動下載、僅 Wi-Fi、僅充電、行動數據上限、預覽、僅前景與單次傳輸覆寫。計量網路上的大型檔案預設只同步中繼資料。
