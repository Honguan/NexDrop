# 用戶端相容性矩陣

[English](compatibility-matrix.md)

目前協議：`1.2`

節點支援目前協議與前兩個用戶端協議世代。能力協商採附加設計：未公布能力時，交集為空並套用文件所列的安全降級。

| 節點 | 用戶端 | 連線 | 可選能力 | 必要行為 |
| --- | --- | --- | --- | --- |
| 1.2 | 1.2 | 支援 | 協商後交集 | 只啟用雙方都公布的行為。 |
| 1.2 | 1.1 | 支援 | 無 | 使用協議 1.1 行為與舊版降級。 |
| 1.2 | 1.0 或 `1` | 支援 | 無 | 使用協議 1.0 行為與舊版降級。 |
| 1.1 | 1.2 | 支援 | 無 | 用戶端接受舊版版本文件並停用可選行為。 |
| 1.0 | 1.2 | 支援 | 無 | 用戶端接受缺少新增欄位並使用協議 1.0 行為。 |
| 更早或未支援的更新協議 | 任意 | 拒絕 | 無 | 回傳穩定的協議升級結果。 |

目前第一方用戶端公布協議 1.2。Web、Extension、Android 與 Windows 都會忽略未知的新增欄位及能力識別碼。

## 棄用與移除

1. 附加能力可在不修改 API 版本下發布。
2. 預定移除的能力至少保留兩個受支援用戶端世代的文件。
3. 除非安全性重大最低版本規則要求提早移除，節點須保留目前與前兩個協議世代。
4. 破壞線上格式的變更必須更新協議版本、混合版本 fixture、發布說明與本矩陣。
5. 已移除的能力識別碼永久保留，不得重複使用。

發布文件檢查會讀取協議常數與能力登錄表；若本矩陣缺少目前協議，或能力文件缺少已登錄識別碼，檢查就會失敗。
