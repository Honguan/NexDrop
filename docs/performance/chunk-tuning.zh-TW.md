# 自適應分段與並行調整

`adaptive_transfer_profile` 能力允許發送端與接收端協商安全上限，並只在已完成分段的邊界調整分段大小或並行數。

## 輸入指標

- 往返延遲與平滑吞吐量
- 重試率與校驗失敗率
- 接收端記憶體與寫入能力
- 儲存回壓
- 電量、溫度與背景限制

## 上限

預設每段 1–32 MiB、同時 1–6 段。有效設定必須符合：

```text
分段大小 * 並行分段數 <= 接收端記憶體預算
```

小檔案固定單流。高延遲、重試、校驗失敗或裝置壓力會降低分段與並行數；快速穩定 LAN 則逐步提高。所有變更均有限幅，避免頻繁震盪。

## 基準設定

- 不穩定或高延遲行動網路：1–2 MiB、單流
- 一般 Wi-Fi：4–8 MiB、1–3 流
- 高速 LAN：16–32 MiB，記憶體允許時最多 6 流

## 驗證矩陣

測試 1 MiB、100 MiB、1 GiB 與多 GiB 檔案，延遲 10/100/250/500 ms，封包遺失 0/1/5/20%。記錄選定設定、吞吐量、重試、校驗失敗、記憶體、儲存回壓與 UI 回應性。

## 相容性

雙方未共同支援時，保留固定協商分段大小與單一傳輸流。兩種模式都沿用既有分段雜湊與續傳資料。
