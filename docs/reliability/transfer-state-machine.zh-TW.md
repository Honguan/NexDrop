# 傳輸復原狀態機

復原以每個傳輸目標為單位執行。單一接收裝置失敗，不會阻塞其他已完成或進行中的裝置。

```text
排隊 -> 執行 -> 驗證 -> 已送達 -> 已讀
  |       |       |
  |       +-> 暫停 -+
  |       +-> 等待接收端
  |       +-> 狀態校正
  |       +-> 退避重試
  |       +-> 死信
  +-> 取消／過期
```

## 不變條件

1. 已驗證分段不可變且可重用。
2. 復原掃描不得重新啟動已完成目標。
3. 每次重試都保留 execution 紀錄，不覆寫歷史。
4. 租約避免兩個協調器同時修改同一目標。
5. 程序或資料庫重啟後可安全重複執行。
6. 終止狀態必須經明確操作才能重試。

## 錯誤分類

- 立即重試：過期鎖定
- 退避重試：資料庫、網路、逾時或 Node 重啟
- 等待：接收裝置離線
- 狀態校正：缺少分段、組裝不完整或遺失確認
- 終止：無效清單、雜湊不符、權限拒絕、裝置撤銷或配額耗盡

持久化佇列會記錄分類、重試次數、下次時間、租約到期、穩定錯誤碼、復原原因與死信時間。
