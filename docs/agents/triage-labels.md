# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Reporter or environment details are required |
| `ready-for-agent` | `ready-for-agent` | Reproduced and fully specified for autonomous work |
| `ready-for-human` | `ready-for-human` | Human-only implementation or judgment is required |
| `wontfix` | `wontfix` | The issue will not be actioned |

Every triaged issue carries exactly one state label from this table and exactly
one category label: `bug` or `enhancement`.
