# Relay Pool 協議

## 註冊與健康

管理員註冊 Relay 端點、區域、容量及釘選身分公鑰。Relay 回報有限健康與容量資料。主要 Node 將長時間未回報的 Relay 標示不健康，並排除不健康、draining 或已滿的端點。

## Grant 格式

簽章 Relay grant 綁定：

- Relay 識別碼
- transfer 與 file 識別碼
- 允許操作：上傳、下載或刪除
- 最大位元組數
- 到期與 nonce

用於其他 Relay、transfer、file、操作或超過大小時必須拒絕。Grant 不包含明文密鑰或永久裝置憑證。

## 分配與 fallback

量測相同時使用決定性選擇。排名納入容量比例、近期失敗率、延遲與區域偏好。失敗時客戶端取得新的授權分配，並重用雜湊符合傳輸清單的分段。

## 清理

分配到期與密文保存期限分離。清理前確認沒有進行中傳輸或有效 grant 引用，再以有限批次移除孤立資料。Relay 重啟不得讓耐久儲存上的已驗證分段失效。

## 指標

提供 Relay 可用性、可用容量、進行中傳輸、吞吐量、授權失敗、分配失敗、drain 進度、孤立數量與清理結果，不暴露端點秘密或內容中繼資料。
