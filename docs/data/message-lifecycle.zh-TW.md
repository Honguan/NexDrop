# 訊息生命週期

## 歷史載入

歷史使用包含 `(created_at, message_id)` 的簽章游標與穩定遞減排序。新訊息不會讓已回傳項目在頁面間移動。客戶端只要求有限頁面，不把大型對話全部載入記憶體。

## 搜尋

因訊息內容端對端加密，全文索引保留在客戶端。本機索引可包含解密文字、檔名、發送裝置、目標裝置、內容類型、日期、送達與已讀狀態。平台允許時使用靜態加密保護索引。

## 已讀狀態

每個裝置維護單調遞增已讀游標。更新具冪等性：較舊或相同游標不能讓狀態倒退。在線狀態與已讀狀態互相獨立。

## 刪除範圍

- 僅本機：移除本機快取項目，不改變其他裝置與 Node 狀態
- 僅附件本體：刪除已下載或 Node 保存本體，保留最小訊息中繼資料
- 所有裝置：發布經授權的簽章版本化 tombstone

離線裝置重新連線時套用有效 tombstone。Tombstone 在設定期限內保留；超過期限才返回的裝置必須執行有限一致性重新整理。

## 參照

釘選訊息與回覆只保存識別碼，不複製訊息內容。被 tombstone 的參照訊息顯示穩定的不可用占位資訊。
