# NexDrop 2.1.0

[English](release-notes-v2.1.0.md)

NexDrop 2.1.0 新增協議 1.2 能力協商。節點與第一方用戶端會選擇共同協議世代，只在能力協商通過後啟用可選行為，並對較舊的 1.1 與 1.0 世代安全降級。

版本端點會發布穩定節點身分、能力登錄表、數值限制及版本指紋。發布檢查會確保登錄表、用戶端宣告、文件與相容性矩陣保持同步。

## 更新

```bash
./deploy/nexdrop update 2.1.0
```

更新會保留 `.env`、PostgreSQL 資料、檔案資料、既有秘密與自動產生的 `NEXDROP_NODE_ID`，並在切換映像前建立備份。
