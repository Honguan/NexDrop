# 資料夾清單協議

資料夾傳輸使用版本化 manifest，不先建立大型暫存壓縮檔。每個一般檔案都能獨立續傳與驗證。

## 第 1 版項目

- 目錄，包含空目錄
- 一般檔案：正規化相對路徑、大小、修改時間、SHA-256、可選 MIME 類型及傳輸檔案識別碼

第 1 版不追蹤或表示符號連結。

## 路徑安全

拒絕絕對路徑、磁碟機路徑、NUL、`..` 穿越、Windows 保留名稱、尾端空白或句點、超過長度、過深巢狀，以及分隔符正規化或大小寫折疊後的衝突。接收端寫入前必須再次驗證 manifest。

## 限制

預設最多 100,000 項、每條路徑 1,024 bytes、64 層、編碼 manifest 32 MiB、宣告總內容 16 TiB。實作可設定更低限制。

## 選擇與衝突

接收端可在本體傳輸前全部接受、全部拒絕或選擇項目，必要父目錄會保留。衝突動作為覆寫、重新命名、略過或詢問。只有大小與 SHA-256 都一致時才自動略過既有檔案。

## 續傳與完成

每個檔案沿用既有已驗證分段。部分失敗不會讓已完成檔案失效。先寫入暫存檔，驗證後在支援的平台原子發布。取消資料夾會停止剩餘工作，並依接收政策保留已完成檔案。

## 相容性

雙方未共同支援 `folder_manifest` 時回傳明確不支援結果。只有發送端明確選擇時才允許壓縮檔 fallback。
