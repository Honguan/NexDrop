# ADR-006：無內容可觀測性與唯讀診斷

[English](006-observability-and-diagnostics.md)

狀態：已接受

## 背景

操作員必須跨 HTTP、WebSocket、Worker 與儲存關聯同一筆傳輸，同時不得揭露訊息內容、明文檔名、憑證或加密材料。指標必須控制 Prometheus 基數，支援封裝也必須可重現且不改變節點狀態。

## 決策

- 儲存僅附加、無內容的傳輸時間線，以 UTC 時間與資料庫序號排序。
- 使用穩定事件碼，以及請求、傳輸、檔案、目標、execution、路由、狀態與錯誤關聯欄位。
- 用戶端只能透過已驗證且具冪等性的端點附加文件列出的用戶端觀察階段；伺服器生命週期事件仍由伺服器管理。
- 以固定名稱及受限的標籤名稱與值輸出作業指標；原始資源識別碼不得成為標籤。
- 透過唯讀檢查路徑產生診斷 ZIP。設定只採公開欄位白名單，已知祕密與憑證形態文字會在壓縮前去敏。
- 只有環境明確標示為可拋棄時，才執行破壞性故障注入。

## 影響

時間線可用來診斷事件順序與復原，且不會成為內容稽核紀錄。新增事件碼或指標標籤值時，必須同步更新契約與雙語文件。診斷新增內容必須通過解壓後洩漏測試，故障情境則必須保持確定且可重複。
