## 棄用與移除

1. 附加能力可在不修改 API 版本下發布。
2. 預定移除的能力至少保留兩個受支援用戶端世代的文件。
3. 除非安全性重大最低版本規則要求提早移除，節點須保留目前與前兩個協議世代。
4. 破壞線上格式的變更必須更新協議版本、混合版本 fixture、發布說明與本矩陣。
5. 已移除的能力識別碼永久保留，不得重複使用。

發布文件檢查會讀取協議常數與能力登錄表；若本矩陣缺少目前協議，或能力文件缺少已登錄識別碼，檢查就會失敗。
