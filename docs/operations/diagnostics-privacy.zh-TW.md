# 診斷隱私與遮蔽

[English](diagnostics-privacy.md)

診斷收集遵循資料最小化：

- 名稱含 `PASSWORD`、`TOKEN`、`SECRET`、`KEY` 或 `CREDENTIAL` 的設定只保留 `[REDACTED]`。
- URL 使用者憑證、Bearer 授權值及敏感查詢參數均會移除。
- 健康檢查內容序列化前會移除已知秘密值。
- 診斷包只使用結構化 JSON；不複製任意日誌、完整環境變數、訊息本文、檔名、索引或已儲存檔案。
- 可保留資源總數與有限狀態／錯誤碼。指標標籤不得使用原始使用者、設備、檔案、訊息、請求或傳輸識別碼。

自動測試會開啟產生的 ZIP，確認代表性的密碼、Token、URL 憑證及 Bearer Token 格式不存在。新增診斷項目時，必須先補上同等的負向測試。
