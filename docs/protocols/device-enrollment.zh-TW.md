# 裝置註冊協議

## 流程

1. 已驗證管理員在 Node 本機使用啟動密鑰要求註冊 grant。
2. Node 回傳短效權杖或 `nexdrop://join` 連結。
3. 新客戶端提交權杖、裝置資訊與 X25519 公鑰。
4. Node 以原子方式消耗一次權杖使用次數、建立裝置身分，並回傳獨立裝置憑證。
5. 客戶端把裝置憑證保存到平台保護儲存區，刪除 Node 密鑰與註冊權杖。

範例：

```text
nexdrop://join?node=https%3A%2F%2Fdrop.example.com&token=<one-time-token>
```

## Grant 限制

- 到期、最大使用次數與指定 Node 身分
- 可選的擁有者、裝置類型及名稱提示
- 傳送檔案權限
- 接收廣播內容權限

並行兌換由 PostgreSQL 序列化，資料庫只保存權杖雜湊。過期、耗盡、撤銷、Node 不符、裝置類型不符與重放都使用穩定版本化錯誤碼。

## 撤銷與輪替

裝置憑證獨立於 Node 密鑰及其他裝置。撤銷單一裝置不得中斷其他裝置。輪替 Node 密鑰只影響之後建立的註冊 grant。

## 舊版遷移

`scoped_device_enrollment` 能力控制新流程。2.x 舊客戶端可在文件化遷移期繼續使用 Node 密鑰建立裝置；UI 必須標示為相容模式並建議重新註冊。
